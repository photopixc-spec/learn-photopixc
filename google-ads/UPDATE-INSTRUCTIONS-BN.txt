Hosting-এ update দিন
১. সাইটের Resources থেকে Backup Export করে progress JSON computer-এ রাখুন।
   এই personal JSON public hosting-এ upload করবেন না। Site data clear নয়।
২. Learning Studio → Settings-এ offline copy চালু থাকলে remove করুন।
৩. Hosting File Manager-এ learn.photopixc.com-এর Document Root খুলুন।
   cPanel → Domains থেকে সঠিক folder নিশ্চিত করুন; অন্য site-এর folder নয়।
৪. বর্তমান site files-এর backup ZIP download করে computer-এ রাখুন।
৫. এই নতুন ZIP সঠিক Document Root-এ upload এবং Extract করুন।
   ZIP root-এ index.html আছে; অতিরিক্ত nested folder তৈরি করবেন না।
   একই নামের site files replace করুন। fonts folder-ও upload হতে হবে।
   নিজের .htaccess, email বা unrelated file মুছবেন না।
৬. Extract-এর পরে index.html এবং fonts folder একই root-এ আছে দেখুন।
   সাধারণ permissions: file 644, folder 755।
৭. Hosting/CDN cache থাকলে purge করুন। Browser-এর সব site tab বন্ধ করে
   আবার খুলুন, তারপর Ctrl+Shift+R (Mac: Cmd+Shift+R) দিন।
৮. ১৭ module / ১০২ lesson এবং Cheat Sheet menu দেখা যাচ্ছে কি না দেখুন।
   পুরোনো সংখ্যা থাকলে আগে cache ও extraction folder যাচাই করুন।
৯. নিচের acceptance checks করুন। ঠিক হলে server থেকে upload ZIP মুছুন।
   Computer-এর backup ও নতুন ZIP রেখে দিন। Offline copy চাইলে আবার enable করুন।
